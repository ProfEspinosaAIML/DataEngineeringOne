# DataEngineeringOne

This project is a beginner-friendly data engineering and Python notebook workshop. It includes introductory Python programming, data engineering exercises, and examples built around the TMDB movie dataset.

## Current status
This repository is currently a work in progress. The notebook exercises, data loading steps, visual examples, and exploratory data analysis activities are being developed and refined as part of the workshop.

## Included in the current state
- Introductory Python programming notebook covering functions, data structures, loops, and practice problems
- Data engineering notebooks and workshop scaffolding
- Python code for loading data from the project data folder
- Basic data queries and filtering examples
- Simple exploratory analysis using pandas
- Correlation and visualization examples using Matplotlib
- Project diagrams in `images/`, including the data engineering life cycle and an ML pipeline
- A workspace agent for diagnosing beginner Python and Jupyter notebook errors

## Project structure
```text
DataEngineeringOne/
├── data/          Raw datasets, including the TMDB movie dataset
├── images/        Workshop diagrams and visual references
├── notebooks/     Python, SQL, and data engineering notebooks
├── prompts/       Project prompts and workshop guidance
├── src/           Reusable project and service code
├── README.md
└── requirements.txt
```

## Getting started
1. Create or activate the project virtual environment.
2. Install the dependencies from `requirements.txt`.
3. Open the notebooks in VS Code or Jupyter.
4. Select the project virtual environment as the notebook kernel.
5. Run the notebook cells in order when exercises depend on earlier variables.
